KluZTD 사용 가이드

다 적고, 분류하고, 보드에서 진행하고, 기록하는 나만의 할 일 관리. 설치부터 매일 쓰는 법까지 한 페이지에 정리했어요.

로컬 전용 — 데이터는 내 컴퓨터에만
macOS 앱 · 브라우저 · 휴대폰(같은 와이파이)
라이트 / 다크

1시작하기

KluZTD 는 서버나 계정이 없습니다. 저장소를 받아 내 컴퓨터에서 빌드해서 씁니다. 처음 한 번만 아래 순서대로 하면 됩니다.

준비물

필요한 것확인 방법없으면
macOS (앱으로 쓸 때)—Windows/Linux 는 브라우저로 쓰기
Node.js 22 이상node -vnodejs.org 에서 LTS 설치, 또는 brew install node
pnpmpnpm -vnpm install -g pnpm 또는 corepack enable
gitgit --version맥은 처음 실행할 때 설치 안내가 뜹니다

맥 앱으로 설치 (추천)

  1. 저장소 받기 
    git clone https://github.com/xxrthscrclz/KluZTD.git
cd KluZTD
  2. 의존성 설치 — Electron 본체도 이때 함께 내려받습니다 (1~3분). 
    pnpm install
  3. 앱 빌드 — release/ 폴더에 KluZTD.app 이 생깁니다. 
    pnpm app:dist
  4. 응용 프로그램 폴더로 옮기기 
    # Apple Silicon 은 mac-arm64, Intel 맥은 mac 폴더
ditto release/mac*/KluZTD.app /Applications/KluZTD.app
    이제 Launchpad · Spotlight 에서 KluZTD 로 실행합니다. Dock 에 두려면 실행 중인 아이콘 우클릭 → 옵션 → Dock 에 유지.
설치 파일(DMG)로 나눠 주고 싶다면pnpm app:dmg → release/KluZTD-버전-arm64.dmg. 서명하지 않은 앱이라 받은 사람은 처음 한 번 우클릭 → 열기 로 열어야 합니다 (아래 문제 해결 참고).

브라우저로 쓰기

앱을 만들지 않고 바로 쓰거나, 맥이 아닌 경우입니다.

pnpm install
pnpm dev          # http://localhost:5173 — 코드 고치면 바로 반영

맥에서는 폴더 안의 KluZTD.command 를 더블클릭해도 됩니다 — 빌드 후 http://localhost:4273 이 열리고, 주소창의 설치 버튼으로 PWA 처럼 설치할 수 있어요. 이 방식은 터미널 창이 켜져 있는 동안만 동작합니다.

휴대폰에서 쓰기

pnpm dev:lan      # 같은 와이파이의 휴대폰에서 http://<맥 IP>:5173
집 · 개인 네트워크에서만데이터 API 가 네트워크에 열립니다. 카페·회사 공용 와이파이에서는 쓰지 마세요. 휴대폰 홈 화면 설치·오프라인 캐시는 HTTPS 에서만 되므로 LAN 에서는 웹으로만 쓰입니다.

2핵심 개념

체크리스트 한 줄 = 상태 관리 카드 하나 = 같은 할 일. 일일 관리에서 적든, 보드에서 만들든, 달력에서 추가하든 모두 같은 할 일이고, 어디서 바꾸든 모든 화면에 반영됩니다.

진행 예정
→
진행 중
→
진행 완료
— 7일 뒤 →
아카이브
  • 대기 — 남에게 넘겼거나 막혀 있는 일. 담당자를 적어 두면 누구 손에 있는지 보입니다.
  • 이슈 — 그날 생긴 문제·메모. 할 일에 연결하면 그 할 일의 상세·카드·프로젝트 어디서나 같은 이슈로 보여요.
  • 프로젝트 — 할 일을 묶는 상위 단위. 프로젝트별로 다음에 할 일(Next Action)과 한 일 기록이 쌓입니다.

3화면별 사용법

왼쪽 메뉴(휴대폰은 아래 메뉴) 또는 숫자키 1–5 로 이동합니다.

일일 관리 1

  • 오늘 할 일을 적으면 상태 관리 «진행 예정» 에도 생기고, 체크하면 «진행 완료» 가 됩니다.
  • 줄의 ⓘ 를 누르면 마감 · 담당자 · 프로젝트 · 우선순위 · 이슈 기록 · 미루기 · 빼기 · 삭제를 할 수 있어요. 정보가 있으면 ⓘ 에 점이, 마감이 지났으면 빨간 점이 찍힙니다.
  • 못 끝낸 일은 날이 바뀌면 자동으로 오늘 체크리스트로 넘어옵니다. 끝낸 일은 그날에 남아요.
  • 오른쪽의 빨간 알림 — 마감이 3일 안(또는 지남)인데 체크리스트에 없는 일. «오늘에 넣기» 로 바로 올립니다.
  • 아래쪽은 그날의 이슈 칸입니다.

상태 관리 2

  • 칸반 보드 — 진행 예정 · 진행 중 · 진행 완료 · 대기. 카드를 끌어다 놓아 상태를 바꿉니다.
  • 진행 중으로 옮기면 오늘 체크리스트에 자동으로 올라갑니다.
  • 위쪽 요약 타일(진행 중 · 마감 지남 · 오늘 마감 …)을 누르면 그 조건으로 걸러 봅니다. 검색은 /.
  • 각 칸의 ＋ 로 그 칸 맨 위에 바로 추가합니다.
  • 카드를 누르거나 Enter 로 상세를 엽니다. 키보드로는 Space 로 집어서 화살표로 옮길 수 있어요.

아카이브

완료한 지 7일이 지나면 자동으로 정리됩니다

진행 완료 칸에는 최근 일주일 안에 끝낸 일만 보입니다. 그보다 오래된 일은 지워지는 게 아니라 아카이브로 넘어가요.

  • 들어가는 길: 진행 완료 칸 아래 «일주일 지난 N개는 아카이브에 →», 또는 상태 관리 오른쪽 위 아카이브 버튼
  • 최근에 끝낸 것부터 월별로 묶여 있고, 제목 · 메모 · 이슈로 검색할 수 있어요.
  • 줄을 누르면 상세가 열리고, 오른쪽 ↺ 를 누르면 «진행 예정» 으로 다시 꺼냅니다.

달력 3

  • 한 달 전체 — 날짜마다 체크리스트 진행(예: 1/3), 그날 마감(점선), 미해결 이슈, 그날 완료한 일이 보입니다.
  • 날짜를 골라 할 일을 추가하면 그날 체크리스트 + 상태 관리에 함께 생깁니다. 일정을 끌어서 다른 날로 옮길 수 있어요.

프로젝트 4

  • Next Action — 손잡이로 끌어서 순서를 정합니다. 순서를 안 정한 일은 그 아래 마감일 가까운 순.
  • 한 일 — 완료 · 시작 · 이슈가 시간순 타임라인으로 쌓입니다.
  • 새 프로젝트는 할 일 상세의 «프로젝트» 칸에 이름을 적고 Enter.

수첩 5 · 자유공간 M

수첩

여러 장의 페이지를 자유롭게 씁니다. 목록은 최근에 고친 순이고 제목 · 본문 검색이 돼요. 쓰는 대로 자동 저장.

자유공간

어느 화면에서나 오른쪽 가장자리의 책갈피. 잠깐 적어 둘 것, 전화 메모 등. 상세가 열려 있어도 열 수 있어요.

6데이터 · 백업

모든 데이터는 JSON 파일 하나에 저장되고, 인터넷으로 나가지 않습니다. 바뀌면 0.6초 뒤 자동 저장 — 왼쪽 아래 점이 초록이면 저장됨, 주황이면 아직 이 기기에만 보관 중입니다.

어떻게 쓰나데이터 파일
맥 앱~/Library/Application Support/KluZTD/kluztd.json
앱 메뉴 데이터 → 데이터 폴더 열기
브라우저 (pnpm dev, KluZTD.command)저장소 폴더의 data/kluztd.json
앱과 브라우저는 서로 다른 파일을 씁니다한쪽에서 적은 게 다른 쪽에 안 보이면 이 때문입니다. 하나만 정해서 쓰거나, 아래처럼 파일을 옮기세요.
  • 자동 백업 — 같은 폴더의 backups/ 에 하루 한 번, 최근 14개를 남깁니다.
  • 브라우저 → 앱으로 옮기기 (앱을 끈 상태에서): 
    cp data/kluztd.json ~/Library/Application\ Support/KluZTD/kluztd.json
  • 다른 맥으로 이사 — 위 kluztd.json 하나만 복사하면 됩니다.
  • 되살리기 — 앱을 끄고 backups/kluztd-날짜.json 을 kluztd.json 으로 덮어쓰기.
  • 삭제는 확인 창 없이 바로 되고, 몇 초간 «되돌리기» 가 뜹니다.
데이터 파일은 git 에 올라가지 않습니다data/ 는 .gitignore 에 들어 있어요. 저장소를 지우거나 다시 받아도 앱 데이터(~/Library/…)는 그대로지만, 브라우저용 data/kluztd.json 은 함께 지워지니 주의하세요.

7업데이트

새 버전이 올라오면 앱을 끄고:

cd KluZTD
git pull
pnpm install
pnpm app:dist
ditto release/mac*/KluZTD.app /Applications/KluZTD.app

데이터는 앱 밖(~/Library/Application Support/KluZTD)에 있어서 앱을 덮어써도 그대로입니다.

8문제 해결

증상해결
«확인되지 않은 개발자» / «손상되었기 때문에 열 수 없습니다»서명하지 않은 앱이라 그렇습니다. Finder 에서 앱 우클릭 → 열기 → 열기. 그래도 안 되면
xattr -dr com.apple.quarantine /Applications/KluZTD.app
«로컬 서버를 열지 못했습니다 (포트 47321)»앱이 이미 켜져 있거나 다른 프로그램이 그 포트를 씁니다. 앱을 완전히 종료(⌘ Q) 후 다시 실행. 확인: lsof -i :47321
pnpm install 후 «Electron failed to install correctly»node node_modules/electron/install.js 를 한 번 실행
할 일이 하나도 안 보임앱과 브라우저는 데이터 파일이 다릅니다 → 데이터 · 백업
오래된 완료 항목이 안 보임정상입니다. 7일 지난 완료 항목은 아카이브에 있어요.
저장 점이 계속 주황브라우저 모드에서 pnpm dev 터미널이 꺼졌는지 확인. 다시 켜면 자동으로 합쳐 저장합니다.
